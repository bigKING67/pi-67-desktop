Status: active
Owner: Claude Code (main session)

Last updated: 2026-10-01

## Goal

Add a `工作 | 聊天` mode switch and a P1 Team Chat: teammates, channels, DMs, text
messages, unread state and real-time push, backed by new-money-server. Contract:
`docs/adr/0003-team-chat.md`.

## Non-goals

- Work Cards / handoff (P2), Agents as members (P3), attachments, search, threads,
  reactions, typing indicators, edits/deletes, native notifications (P4).
- Web console chat UI. Team invitations stay in the existing web console.
- Any VPS deployment, migration run against production, commit or push without
  separate authorization.

## Acceptance criteria

- Signed-in Desktop shows the mode switch; Work is unchanged; Chat lists teammates,
  channels and DMs for the device-authorized team.
- A message sent from one client appears on another within ~1s via WSS, survives a
  dropped socket through REST reconciliation, and is never duplicated on retry.
- Unread counts derive from `lastSeq/lastReadSeq` and clear when a conversation is read.
- Signed-out or non-team Desktop shows a truthful Chat empty state; Work keeps working.
- Removing a member denies their next request and closes their sockets.
- No chat body, ticket or token is logged on either side.

## Delivery boundary

- Local implementation: both repositories, source + tests + authority docs.
- Commit: only on explicit request.
- Push: not authorized.
- Candidate build/upload: not authorized; local `preview:mac:unsigned` allowed.
- Tag/release/promotion and VPS deployment/migration: not authorized.

## Decisions

| Decision | Rationale | Reversal condition |
| --- | --- | --- |
| Outbound WSS push + REST mutations/reconcile | Lowest latency; REST keeps idempotency and errors uniform | Proxy path proves WSS unreliable |
| Single-use 60s ticket for WSS auth | Avoids bearer token in URL; works for future Web client | Node WebSocket header auth becomes the only client |
| Per-conversation `seq` and member `lastReadSeq` | Gap detection and unread without a team event log | Need cross-conversation ordered feed |
| In-process per-team broadcast hub | One API instance today | More than one API instance |
| Host owns client and socket | ADR 0002 business networking; P3 agent turns live there | Host restarts prove too disruptive |
| Mode switch in navigation rail header | DESIGN.md: nav controls stay in navigation zone | Usability evidence |
